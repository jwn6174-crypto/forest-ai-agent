# 방법 — Faustmann-Hartman 한국 변형 + 8 학자 deliberation

## 수식

```
NPV(T) = Σ_g [p_g · v_g(T)] · e^(-rT)      ← 등급별 원목 (KOFPI Q4 2025)
       + ∫ p_C(t) · ΔC(t) · e^(-rt) dt    ← 탄소 (국립산림과학원 3,212 표본)
       + ∫ π_NTFP(t) · e^(-rt) dt          ← 임산물 (산림청 2024)
       + subsidy_revenue                    ← 보조사업 (산림청 2025)
       − Cost(T) · e^(-rT)                 ← 표준품셈 + KOFPI 5/5
       − L_C(T) [IPCC 2019 HWP decay]      ← 35/25/2년 half-life

LEV = NPV / (1 − e^(-rT))
```

## 8 전문가 deliberation
산림학자 · 산림경제학자 · 산림정책학자 · 산림경영자(실무) · AI 엔지니어
+ 위성/원격탐사 · 영세 산주 · 산림경제정책 통합자
