## D1: KOFPI 데이터 — 수종별 확장 (옵션 B)

**날짜**: 2026-05-13 (Day 2 후반)

**상황**:
가이드 §6.3 의 `market_snapshot()` 시그니처는 `timber_price` (소나무 기본 6 등급) 만 요구. 그러나 KOFPI 분기별 보고서에서 *7 수종 × 6 등급* 모두 추출 가능.

**대안 비교**:

| 옵션 | 내용 | 정확도 | 가이드 매칭 |
|---|---|---|---|
| A. 가이드 시그니처만 | 소나무 1수종 6 등급 | NPV 부정확 | 100% |
| B. 가이드 + 수종별 확장 | 7 수종 × 6 등급 | NPV 정확 | 100% (확장) |
| C. 수종별만 | 가이드 시그니처 무시 | NPV 정확 | 위반 |

**선택**: 옵션 B

**근거**:
- 수종별 가격 차이 *22-47%* (소나무 1등급 199,700원 vs 리기다소나무 105,400원)
- NPV 결정적 영향 → *시연 임팩트 큼*
- 가이드 시그니처 *유지* + *추가 정보 제공* = *호환성 + 정확성*
- 희도가 NPV 계산 시 `snap["timber_price_by_species"][species]` 호출 가능

**한계**:
- KOFPI 시계열 *4 분기 (12개월) 만* — 2014-2024 깊은 시계열은 *원본 PDF 추가 다운로드 필요*
- 단일 시점 가격 → *Faustmann real-price-constant 가정* 따름 (가이드 §6.3 의 표준)
- 미래 가격 예측 *안 함* (가이드도 안 함)

## D2: 표준품셈 → 비용 함수 — 옵션 Y (진짜 PDF 추출 + 간단 모델)

**날짜**: 2026-05-13 (Day 2 후반)

**상황**:
가이드 §7.1 은 *placeholder 값* 제공 (예: `harvest_unit_cost: 45,000원/m³`) 후 "(예시 — 실제 PDF 확인 후 입력)" 주석. 진짜 PDF (산림청 고시 제2025-82호, 257p) 다운로드 후 진단 결과:
PDF 는 원·m³ 단위 가격 아님.
실제 구조 = 소요인력 (인/단위) + 시중노임단가 (별도) + 할증률 (26개) 3 요소 모델.
예시:
PDF 에 있음: "벌채 1m³ → 보통인부 0.05 인 필요"
PDF 밖:    "보통인부 1인 1일 = 180,000원" (대한건설협회 별도 공포)
→ 실제 벌채비 = 0.05 × 180,000 × 할증률

**대안 비교**:

| 옵션 | 추출 범위 | 정확도 | 시간 |
|---|---|---|---|
| X. 완전 추출 | 50-100개 작업 + 26개 할증 + 자재단가 | 95-100% | 4-6시간 |
| Y. 간단 모델 | 주요 4-5개 작업 + 기본 3개 할증 | 75-85% | 1.5-2시간 |
| Z. Placeholder | 가이드 예시값 그대로 (PDF 안 씀) | 가이드 함정 그대로 | 30분 |
| W. 학습 메모 + 마무리 | 추출 안 함, 진단만 기록 | — | 45분 |

**선택**: 옵션 Y

**근거**:
- 가이드 §7.1: "(예시 — 실제 PDF 확인 후 입력)" → *확인* 만 요구, *완전 추출* 요구 *아님*
- 가이드 §8 (Week 5 통합): 시연 정확도 *80%+ 충분*
- `COST_PARAMS` *5개 변수만* — 옵션 Y 가 *5개 변수 진짜 PDF 기반* 제공 가능
- 옵션 X 는 *오버 엔지니어링* (Week 4-5 일정 초과)
- 옵션 Z 는 *PDF 다운받고도 안 씀* — 정우 마인드 ("정확한 걸 선호") 와 충돌
- 옵션 Y 는 *추후 옵션 X 로 확장 가능* — 함수 시그니처 동일, `COST_PARAMS` dict 값만 교체

**한계**:
- 정확도 75-85% (옵션 X 의 95%+ 보다 낮음)
- 시중노임단가 *가이드 추정값* (170,000-200,000원/인일) 사용 — 대한건설협회 자료 *별도 작업*
- 자재단가 (묘목·연료·기계 손료) *생략*
- 26개 할증률 중 *기본 3개만* (경사도, 이동거리, 작업시기)
- 추후 *옵션 X 로 확장* 시 코드 구조 *유지*, `COST_PARAMS` 만 교체

## D3: cost_function() — KOFPI 우선 + 표준품셈 보완 (5/5 진짜 데이터)

**날짜**: 2026-05-13 (Day 2 후반)

**상황**:
가이드 §7.1 의 5개 변수 (`harvest_unit_cost`, `skidding_cost_per_m3_km`, `transport_cost_per_m3_km`, `regen_cost_per_ha`, `admin_overhead`) 의 placeholder 값을 *진짜 PDF 데이터* 로 정정.

표준품셈 PDF (산림청 고시 제2025-82호, 257p) 진단 결과:
- 표준품셈은 *소요인력 (인/m³, 인/ha)* 만 제공. *km당 단가* 직접 없음.
- 즉 가이드의 *선형 단가 모델* (단가 × 거리) 과 *간접* 매칭.

KOFPI 분기별 보고서 진단 결과 (정우 발견 ⭐):
- 제4장 *거리별 운반비 산정내역* = *대운반비 (50km 구간)* + *소운반비 (m 구간)* 직접 제공.
- 가이드의 *선형 단가 모델* 과 *직접* 매칭.

**대안 비교**:

| 옵션 | 데이터 출처 | 정확도 | 가이드 매칭 | 시간 |
|---|---|---|---|---|
| Z. Placeholder | 가이드 추정값 그대로 | 가이드 함정 그대로 | 100% | 30분 |
| Y. 표준품셈만 | 표준품셈 + 노임 (간접 모델) | 75-85% | 80% | 2-3시간 |
| **Y+** (선택) | **KOFPI 우선 + 표준품셈 보완** | **95%+** | **100%** | **3-4시간** |
| X. 완전 추출 | 표준품셈 26개 할증 전체 | 95-100% | 100% | 6-8시간 |

**선택**: 옵션 Y+ (KOFPI 우선 + 표준품셈 보완)

**근거**:
- KOFPI 운반비 = *실제 시장 거래 가격* (산림청 분기별 조사)
- 표준품셈 운반비 = *공식 추정 가격* (재구성 필요)
- 가이드 §7.1 의 모델 (단가 × 거리) → KOFPI 가 *직접 매칭*
- 가이드 §7.1 의 *placeholder 함정* 발견 + 정정:
  - `skidding_cost_per_m3_km: 3,500원` → KOFPI 진짜 *9,300-18,400원/m³* (3-6배 차이)
  - `transport_cost_per_m3_km: 1,200원` → KOFPI 진짜 *14,600-36,200원/m³* (구간별)
- 정우 직감 "KOFPI 가 더 정확" — 검증 후 채택

**데이터 매핑 (최종)**:
| 변수 | 출처 | 데이터 |
|---|---|---|
| harvest | 표준품셈 p.59-60 + 대한건설협회 노임 | 벌목부 25.5 m³/인일 × 248,140원/인일 |
| skidding | KOFPI 보고서 p.44 (소운반비) | 9,300원/m³ (500-1km) ~ 18,400원/m³ (2-4km) |
| transport | KOFPI 보고서 p.43 (대운반비) | 14,600원/m³ (50km) ~ 36,200원/m³ (300km+) |
| loading | KOFPI 보고서 (상차비) | 5,800원/m³ (2025 Q4) |
| regen | 표준품셈 p.73 + 대한건설협회 노임 | 1.33 특별인부 + 20 보통인부 + 4,000본 묘목 |
| admin_overhead | 가이드 §7.1 | 0.15 |

**검증 결과** (강원소나무 1ha 개벌, 280m³, 도로 15km, 중경사):
- 총 비용: **21,599,743원**
- 단가별 분해: harvest 13.2%, skidding 12.7%, transport 18.9%, loading 7.5%, regen 34.6%, admin 13.0%
- 거리 영향: 5km vs 300km = 32% 비용 증가
- 산림조합 실제 견적과 *근접* — 현실적 수치

**한계**:
- 묘목 단가 (800원/본) 는 *추정값* — 산림용 종자·묘목 고시 별도 확인 필요
- 보육·간벌 *재투입* 비용 미반영 (개벌 단순화)
- KOFPI 운반비 *전국 평균* — 충북 보은 지역 특화 X
- 표준품셈 26개 할증 중 *경사도 (1-4-5) 만* 반영 — 작업시기·이동거리·집단화정도 등 추후
- 운반비 *구간형* (50km 단위) — 5km 와 30km 가 같은 단가 (KOFPI 표 구조 한계)

**시연 가치**:
- 가이드 §7.1 의 *placeholder 함정 발견 + 정정* 자체가 *학술 기여*
- 5/5 진짜 데이터 출처 추적 가능 → 심사위원·대학원 *반박 어려움*
- 정우의 *직감* 이 *프로젝트 결정적 분기점* — 데이터 우선 선택 패턴

## D4: shared/schemas.py — 가이드 §8.1 + 우리 확장 (옵션 P2)

**날짜**: 2026-05-13 (Day 2 마감)

**상황**:
가이드 §8.1 의 4개 Pydantic 모델 (GrowthForecast, MarketSnapshot, CostFunction, RotationRule) 을 정의해야 함. 그러나 우리가 구현한 함수의 *반환 데이터* 가 가이드 §8.1 명세보다 *풍부* 함:

- `market_snapshot()`: 가이드는 `timber_price` (소나무 6 등급) 만. 우리는 `timber_price_by_species` (7 수종), `timber_price_meta` (출처), `kau_meta` 등 *확장 자산* 보유.
- `growth_predict()`: 가이드는 `volume/dbh/height/n_per_ha trajectory`. 우리는 `tmai_trajectory`, `method`, `warning` 추가.
- `rotation_age()`: 가이드는 3 필드. 우리는 `legal_basis`, `species_category` 추가.
- `cost_function()`: 가이드의 `CostFunction` 명세가 *함수 입력 변수* 모델로 모호 → 우리는 `CostInput` (입력) + `CostBreakdown` (출력) *분리*.

**대안 비교**:

| 옵션 | 가이드 매칭 | 우리 자산 보존 | 복잡도 |
|---|---|---|---|
| P1. 가이드 명세 그대로 | 100% | 0% (자산 손실) | 단순 |
| **P2** (선택) | **100%** | **100% (Optional 확장)** | **중간** |
| P3. 우리 자유 설계 | 80% | 100% | 복잡 |

**선택**: 옵션 P2 — 가이드 §8.1 기본 필드 *100% 호환* + 우리 확장 필드 *Optional* 추가

**근거**:
- 가이드 호환성 100% → 희도 NPV 작성 시 *가이드대로 호출* 가능
- 우리 풍부한 자산 (수종별 가격, 출처 메타) *Optional 활용* 가능
- *후방 호환성* — 가이드 명세만으로도 모델 생성 가능 (검증 5개 통과)
- 정직히 *가이드 vs 우리 확장* 차이 *주석 명시* — 학술 투명성
- 정우 관점: "가이드는 *나침반*. 토씨 하나까지 따라야 하는 건 아님."

**결과 구조**:

```python
# 가이드 §8.1 매칭 (필수 필드)
class MarketSnapshot(BaseModel):
    date: str
    timber_price: Dict[str, Optional[int]]
    kau_close: Optional[float]
    koc_estimate: Optional[float]
    vcm_floor_wta: float = 17039
    discount_rate: float = 0.05
    
    # 우리 확장 (Optional)
    timber_price_by_species: Optional[Dict[str, Dict[str, Optional[int]]]] = None
    timber_price_meta: Optional[Dict[str, Any]] = None
    kau_meta: Optional[Dict[str, Any]] = None
```

**검증 결과** (5개 스키마, 자가 테스트):
- ✅ MarketSnapshot — 가이드 기본만으로 생성 가능
- ✅ MarketSnapshot — 우리 확장 포함 생성 가능
- ✅ RotationRule — 가이드 + 우리 확장
- ✅ CostInput + CostBreakdown — 입력·출력 분리
- ✅ GrowthForecast — `from_trajectory_dicts()` 헬퍼 작동

**한계**:
- `grade_distribution_trajectory` (가이드 §8.1) 는 Optional — Weibull fit 후 추후 채움
- `carbon_uptake_rate` (가이드 §8.1) 도 Optional — 산림탄소 모델 통합 추후

**시연 가치**:
- 가이드 §8.1 *100% 호환* — 심사위원 매칭 검증 가능
- *Optional 확장* 으로 우리 풍부한 자산 활용 가능
- 팀 협업 *진짜 인프라* — 희도·수범이 IDE 자동완성으로 *빠른 작업*

## D5: carbon_uptake_rate — growth_predict() 통합 (Day 3)

**날짜**: 2026-05-15 (Day 3)

**상황**:
가이드 §8.1 의 `GrowthForecast.carbon_uptake_rate: List[float]` 필드가 *Optional* 로만 있었음. Faustmann NPV 가 *탄소상쇄 수입* 을 계산하려면 *수종·임령별 탄소흡수량 (tCO2/ha/yr)* 데이터 필수.

또한 정우 발견 (Day 2): KAU 종가 (17,200원/tCO2) ≈ 박2020 WTA (17,039원/tCO2). 시장 가격이 산주 의지가격 *바로 위* → 탄소상쇄 사업 *경제성 진입 시점*. 이걸 시연 시 *진짜 수치* 로 보여주려면 `carbon_uptake_rate` 통합 필수.

**대안 비교**:

| 옵션 | 데이터 출처 | 정확도 | 한국 매칭 | 시간 |
|---|---|---|---|---|
| C1. IPCC 2006 기본값 | 국제 일반 계수 | 70% | 낮음 | 30분 |
| **C2** (선택) | **국립산림과학원 표준** | **95%** | **100%** | **1-1.5시간** |
| C3. 학술 논문 개별 종합 | 연구마다 다름 | 변동 큼 | 보통 | 3-4시간 |

**선택**: 옵션 C2 — 국립산림과학원 표준 탄소흡수량 (2003 개발, 2013/2024 개정)

**근거**:
- 한국 *공식 국가 표준* — UNFCCC IPCC 표준법 + 한국 자료 (3,212 표본 × 40년)
- 주요 8개 수종 (소나무, 잣나무, 낙엽송, 리기다, 편백, 참나무 등) 직접 매핑
- 임령별 (10/20/30/40/50/60년) 데이터 → 선형 보간으로 임의 임령 가능
- 산림청·환경부 공식 인용 가능
- *학술적 반박 어려움*

**구현 방식**:
1. `module_bd/data/raw/carbon/carbon_uptake_2003.json` 학술 자산 보관 (출처·법적 근거·단위 명시)
2. `_lookup_carbon_uptake(species, age)` 헬퍼 함수 추가 (`growth_predict.py`)
3. `growth_predict()` 의 trajectory dict 에 `carbon_uptake_rate` 추가
4. 수종 별칭 매핑 (강원소나무 → "소나무", 신갈/굴참/상수리 → "참나무" 등)
5. 임령 보간 (10년 단위 데이터 → 임의 임령) — 선형 보간

**검증 결과** (강원소나무 SI=14):
- 30년: 10.77 tCO2/ha/yr (탄소 흡수 *피크*) ✅
- 40년: 7.19 (감소 시작)
- 50년: 4.92 (피크의 46%, *감소*)
- 60년: 7.35 (별도 출처 데이터)
- 잠정 수종 (백합나무, 자작나무): 데이터 없음 → 정직한 warning ✅

**시연 인사이트** (이 통합으로 가능):
- "벌채 후 재조림 → 젊은 숲 유지 → 탄소 ↑" *학술적 증명*
- KAU 17,200원 × 흡수량 = *진짜 탄소 수입 시뮬레이션*
- 30년 vs 50년 NPV 비교 시 *탄소 수입* 까지 합산 가능
- 가이드 §6.4 의 *산림탄소상쇄 사업 논리* 정확 매칭

**예시 NPV 영향** (강원소나무 1ha, 50년까지 키울 시):
- 20년간 평균 흡수: 약 7.6 tCO2/ha/yr × 20년 × 1ha = 152 tCO2
- 탄소 수입: 152 × 17,200원 (KAU) = 2,614,400원
- 원목 수입 대비 약 5% 추가 (현재 가격 기준)
