## D1: KOFPI 데이터 — 수종별 확장 (옵션 B)

**날짜**: 2026-05-13 (Day 2 후반)

**상황**:
가이드 §6.3 의 `market_snapshot()` 시그니처는 `timber_price` (소나무 기본 6 등급) 만 요구. 그러나 KOFPI 분기별 보고서에서 *7 수종 × 6 등급* 모두 추출 가능.

**대안 비교**:

| 옵션 | 내용 | 정확도 | 가이드 매칭 |
|---|---|---|---|
| A. 가이드 시그니처만 | 소나무 1수종 6 등급 | NPV 부정확 | 100% |
| B. 가이드 + 수종별 확장 | 7 수종 × 6 등급 | NPV 정확 | 100% (확장) |
| C. 수종별만 | 가이드 시그니처 무시 | NPV 정확 | 위반 |

**선택**: 옵션 B

**근거**:
- 수종별 가격 차이 *22-47%* (소나무 1등급 199,700원 vs 리기다소나무 105,400원)
- NPV 결정적 영향 → *시연 임팩트 큼*
- 가이드 시그니처 *유지* + *추가 정보 제공* = *호환성 + 정확성*
- 희도가 NPV 계산 시 `snap["timber_price_by_species"][species]` 호출 가능

**한계**:
- KOFPI 시계열 *4 분기 (12개월) 만* — 2014-2024 깊은 시계열은 *원본 PDF 추가 다운로드 필요*
- 단일 시점 가격 → *Faustmann real-price-constant 가정* 따름 (가이드 §6.3 의 표준)
- 미래 가격 예측 *안 함* (가이드도 안 함)

## D2: 표준품셈 → 비용 함수 — 옵션 Y (진짜 PDF 추출 + 간단 모델)

**날짜**: 2026-05-13 (Day 2 후반)

**상황**:
가이드 §7.1 은 *placeholder 값* 제공 (예: `harvest_unit_cost: 45,000원/m³`) 후 "(예시 — 실제 PDF 확인 후 입력)" 주석. 진짜 PDF (산림청 고시 제2025-82호, 257p) 다운로드 후 진단 결과:
PDF 는 원·m³ 단위 가격 아님.
실제 구조 = 소요인력 (인/단위) + 시중노임단가 (별도) + 할증률 (26개) 3 요소 모델.
예시:
PDF 에 있음: "벌채 1m³ → 보통인부 0.05 인 필요"
PDF 밖:    "보통인부 1인 1일 = 180,000원" (대한건설협회 별도 공포)
→ 실제 벌채비 = 0.05 × 180,000 × 할증률

**대안 비교**:

| 옵션 | 추출 범위 | 정확도 | 시간 |
|---|---|---|---|
| X. 완전 추출 | 50-100개 작업 + 26개 할증 + 자재단가 | 95-100% | 4-6시간 |
| Y. 간단 모델 | 주요 4-5개 작업 + 기본 3개 할증 | 75-85% | 1.5-2시간 |
| Z. Placeholder | 가이드 예시값 그대로 (PDF 안 씀) | 가이드 함정 그대로 | 30분 |
| W. 학습 메모 + 마무리 | 추출 안 함, 진단만 기록 | — | 45분 |

**선택**: 옵션 Y

**근거**:
- 가이드 §7.1: "(예시 — 실제 PDF 확인 후 입력)" → *확인* 만 요구, *완전 추출* 요구 *아님*
- 가이드 §8 (Week 5 통합): 시연 정확도 *80%+ 충분*
- `COST_PARAMS` *5개 변수만* — 옵션 Y 가 *5개 변수 진짜 PDF 기반* 제공 가능
- 옵션 X 는 *오버 엔지니어링* (Week 4-5 일정 초과)
- 옵션 Z 는 *PDF 다운받고도 안 씀* — 정우 마인드 ("정확한 걸 선호") 와 충돌
- 옵션 Y 는 *추후 옵션 X 로 확장 가능* — 함수 시그니처 동일, `COST_PARAMS` dict 값만 교체

**한계**:
- 정확도 75-85% (옵션 X 의 95%+ 보다 낮음)
- 시중노임단가 *가이드 추정값* (170,000-200,000원/인일) 사용 — 대한건설협회 자료 *별도 작업*
- 자재단가 (묘목·연료·기계 손료) *생략*
- 26개 할증률 중 *기본 3개만* (경사도, 이동거리, 작업시기)
- 추후 *옵션 X 로 확장* 시 코드 구조 *유지*, `COST_PARAMS` 만 교체

## D3: cost_function() — KOFPI 우선 + 표준품셈 보완 (5/5 진짜 데이터)

**날짜**: 2026-05-13 (Day 2 후반)

**상황**:
가이드 §7.1 의 5개 변수 (`harvest_unit_cost`, `skidding_cost_per_m3_km`, `transport_cost_per_m3_km`, `regen_cost_per_ha`, `admin_overhead`) 의 placeholder 값을 *진짜 PDF 데이터* 로 정정.

표준품셈 PDF (산림청 고시 제2025-82호, 257p) 진단 결과:
- 표준품셈은 *소요인력 (인/m³, 인/ha)* 만 제공. *km당 단가* 직접 없음.
- 즉 가이드의 *선형 단가 모델* (단가 × 거리) 과 *간접* 매칭.

KOFPI 분기별 보고서 진단 결과 (정우 발견 ⭐):
- 제4장 *거리별 운반비 산정내역* = *대운반비 (50km 구간)* + *소운반비 (m 구간)* 직접 제공.
- 가이드의 *선형 단가 모델* 과 *직접* 매칭.

**대안 비교**:

| 옵션 | 데이터 출처 | 정확도 | 가이드 매칭 | 시간 |
|---|---|---|---|---|
| Z. Placeholder | 가이드 추정값 그대로 | 가이드 함정 그대로 | 100% | 30분 |
| Y. 표준품셈만 | 표준품셈 + 노임 (간접 모델) | 75-85% | 80% | 2-3시간 |
| **Y+** (선택) | **KOFPI 우선 + 표준품셈 보완** | **95%+** | **100%** | **3-4시간** |
| X. 완전 추출 | 표준품셈 26개 할증 전체 | 95-100% | 100% | 6-8시간 |

**선택**: 옵션 Y+ (KOFPI 우선 + 표준품셈 보완)

**근거**:
- KOFPI 운반비 = *실제 시장 거래 가격* (산림청 분기별 조사)
- 표준품셈 운반비 = *공식 추정 가격* (재구성 필요)
- 가이드 §7.1 의 모델 (단가 × 거리) → KOFPI 가 *직접 매칭*
- 가이드 §7.1 의 *placeholder 함정* 발견 + 정정:
  - `skidding_cost_per_m3_km: 3,500원` → KOFPI 진짜 *9,300-18,400원/m³* (3-6배 차이)
  - `transport_cost_per_m3_km: 1,200원` → KOFPI 진짜 *14,600-36,200원/m³* (구간별)
- 정우 직감 "KOFPI 가 더 정확" — 검증 후 채택

**데이터 매핑 (최종)**:
| 변수 | 출처 | 데이터 |
|---|---|---|
| harvest | 표준품셈 p.59-60 + 대한건설협회 노임 | 벌목부 25.5 m³/인일 × 248,140원/인일 |
| skidding | KOFPI 보고서 p.44 (소운반비) | 9,300원/m³ (500-1km) ~ 18,400원/m³ (2-4km) |
| transport | KOFPI 보고서 p.43 (대운반비) | 14,600원/m³ (50km) ~ 36,200원/m³ (300km+) |
| loading | KOFPI 보고서 (상차비) | 5,800원/m³ (2025 Q4) |
| regen | 표준품셈 p.73 + 대한건설협회 노임 | 1.33 특별인부 + 20 보통인부 + 4,000본 묘목 |
| admin_overhead | 가이드 §7.1 | 0.15 |

**검증 결과** (강원소나무 1ha 개벌, 280m³, 도로 15km, 중경사):
- 총 비용: **21,599,743원**
- 단가별 분해: harvest 13.2%, skidding 12.7%, transport 18.9%, loading 7.5%, regen 34.6%, admin 13.0%
- 거리 영향: 5km vs 300km = 32% 비용 증가
- 산림조합 실제 견적과 *근접* — 현실적 수치

**한계**:
- 묘목 단가 (800원/본) 는 *추정값* — 산림용 종자·묘목 고시 별도 확인 필요
- 보육·간벌 *재투입* 비용 미반영 (개벌 단순화)
- KOFPI 운반비 *전국 평균* — 충북 보은 지역 특화 X
- 표준품셈 26개 할증 중 *경사도 (1-4-5) 만* 반영 — 작업시기·이동거리·집단화정도 등 추후
- 운반비 *구간형* (50km 단위) — 5km 와 30km 가 같은 단가 (KOFPI 표 구조 한계)

**시연 가치**:
- 가이드 §7.1 의 *placeholder 함정 발견 + 정정* 자체가 *학술 기여*
- 5/5 진짜 데이터 출처 추적 가능 → 심사위원·대학원 *반박 어려움*
- 정우의 *직감* 이 *프로젝트 결정적 분기점* — 데이터 우선 선택 패턴
